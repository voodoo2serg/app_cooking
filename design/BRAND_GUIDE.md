# «Вкус детства» — фирменный стиль 1.0

## Идея

Дом означает место, где рецепт передают дальше; сердце над трубой — тепло конкретных людей и воспоминаний. Визуальный язык соединяет кремовую бумагу семейной тетради, выразительный терракотовый знак, зелёный цвет действий и крупные настоящие фотографии. В интерфейсе важнее читать историю и узнавать людей, чем украшать каждую карточку. Знак строится из простого объёма дома, крыши и сердца с коротким изгибом дыма; окон, двери и кухонных предметов нет.

Основное направление — **терракота**. Янтарь и коралл ниже служат цветовыми альтернативами, которые не нужно смешивать в одном интерфейсе. Для CTA принят глубокий зелёный; терракота выделяет бренд и основные действия Material 3.

## Типографика

Два семейства: характерный **serif** для заголовков и нейтральный **sans serif** для управления и текста. Код использует системные `FontFamily.Serif` и `FontFamily.SansSerif`: это работает офлайн без загрузки шрифтов. Для дальнейшей редакционной версии можно лицензировать и встроить PT Serif и Golos Text, затем заменить семейства в одном файле. Ниже шкала Material 3; трекинг в `sp`, межстрочный интервал в `sp`.

| Стиль | Размер / строка | Вес | Трекинг | Применение |
|---|---:|---|---:|---|
| displayLarge / Medium / Small | 57/64, 45/52, 36/44 | Regular serif | −0.25, 0, 0 | промо, обложка |
| headlineLarge / Medium / Small | 32/40, 28/36, 24/32 | Regular serif | 0 | заголовки экранов |

## Сетка и компоненты UI-kit

Базовая сетка `8dp`, боковой отступ `16dp`, промежуток между элементами `8/16/24dp`. Карточки `12dp`, кнопки `8dp`, модальные окна `24dp`; высота кнопки `48dp`, текстового поля `56dp`, нижней навигации `64dp`. Карточки используют очень лёгкую высоту `2dp` или тонкую границу. Для доступности интерактивная зона иконки минимум `48×48dp`.

| Компонент | Геометрия и содержание | Состояния |
|---|---|---|
| Primary button | 48dp, терракота, белая метка, 8dp радиус | enabled, pressed, disabled, loading |
| Secondary / text / icon button | 48dp зона, зелёный контур или текст | enabled, pressed, disabled; у icon есть подпись для accessibility |
| Поле ввода | 56dp минимум, подпись, ввод, помощь | idle, focused, filled, error, disabled; сообщение об ошибке под полем |
| Карточка рецепта | фото 4:3, название, время, 1–2 чипа; радиус 12dp | обычная, нажата, без фото, избрана |
| Карточка человека | фото 48–64dp, имя, связь, число рецептов | обычная, нажата, фото отсутствует |
| Карточка версии | дата, отличие, фото, 3 оценки при наличии | обычная, раскрыта, без фото |
| Чип | высота 32dp, внутренние отступы 12dp | selected, unselected, disabled |
| Нижняя навигация | 64dp: Главная, Рецепты, Семья, Подбор, Книга | selected с подписью и заливкой, unselected; Настройки через меню |
| FAB | 56dp, плюс и подпись через accessibility | обычная, нажата, disabled |
| Аудиоплеер | 48dp кнопка, шкала, длительность | запись, пауза, воспроизведение, разрешение отклонено |
| Пустое состояние | маленький знак/фото, заголовок, пояснение, CTA | нет рецептов, пустой поиск, нет снимков |
| Диалог / bottom sheet | 24dp верхние углы, действия внизу | подтверждение, ошибка, отмена |
| Paywall | фото книги, ценность, цена и срок, покупка, восстановление | доступно, загрузка, ошибка, уже куплено; цены только из магазина |

Здесь описан полный набор; некоторые компоненты, например paywall, остаются спецификацией и **не включены** в нынешний MVP. Не показывать фиктивную покупку. Три оценки «Легендарный вкус», «Простота приготовления» и «Семейная память» подписывать словами рядом со шкалой 1–5, не полагаться на один цвет.

## Иконки, фотографии, фон

`icons/*.svg` содержит 11 согласованных пиктограмм 24×24: рецепт, человек, поиск, камера, микрофон, PDF, сердце, дом, поделиться, настройки, премиум. Линия `1.75`, округлённые концы и стыки. Значок бренда остаётся отдельным залитым силуэтом. В Android-проект пока встроена launcher-иконка; остальные SVG служат исходниками UI-kit и требуют отдельного подключения при обновлении экранов.

Еда — естественный мягкий боковой свет, тёплый баланс белого без сильного оранжевого фильтра; показывать само блюдо и семейный контекст. Для карточки — 4:3, обложки книги — 16:9, портрет человека — 1:1 с ручным кадрированием. При отсутствии фото — кремовая подложка и маленький знак, без чужих стоковых лиц. Фото «Как мы это едим» показывать как отдельный семейный момент, не выдавать его за инструкцию к рецепту.

Фоновый паттерн допускается только на пустом состоянии или обложке: повторение контура домика с непрозрачностью около 5%. Не накладывать его на пользовательские снимки и длинный текст.

## Передача в код

`VkusTheme` содержит light/dark `ColorScheme`, все 15 стилей `Typography` и `BrandDimens`. `MainActivity` уже оборачивает экраны в тему; `UiComponents` берёт фон, текст и карточки из `MaterialTheme`. `AndroidManifest.xml` подключает adaptive icon. Для смены брендового цвета обновите `BrandColors`, соответствующий `icon_background` и SVG/экспорт; сохраните контрастные `on*` роли. SVG открываются в Figma как вектор, а PNG из `previews/` помогают сверить масштаб. Генерация исходников: `python3 design/make_assets.py` и `python3 design/make_icons.py` (для PNG требуется Inkscape и Pillow).
