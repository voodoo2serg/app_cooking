# Подпись приложения

`vkus.jks` — единственный ключ подписи APK «Вкус детства».

Зачем он в репозитории: если каждый билд подписывать случайным debug-ключом
(так делает CI, у которого нет общего keystore), Android не даёт ставить новый APK
поверх установленного приложения — виден сбой «приложение не установлено».
Один общий ключ решает это: все сборки (локальные и на GitHub Actions) взаимозаменяемы
и ставятся как обновление.

Отпечаток сертификата SHA-256:

```
A6:06:17:45:C2:B8:3A:C5:06:DE:EB:2C:64:CF:7F:0B:0C:47:87:1C:22:B3:DB:EB:66:67:A9:B6:F4:40:30:83
```

Проверка на уже установленном приложении (нужен тот же отпечаток):

```
adb shell dumpsys package ru.vkusdetstva | grep -A1 "Signatures"
```

Пароли лежат в `vkus-signing.properties` рядом. Для личного/семейного проекта это
осознанный компромисс; при публикации в Google Play ключ нужно будет вынести в секреты CI.
