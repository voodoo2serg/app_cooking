# Вкус детства — Android MVP

Исходный проект Android-приложения для семейных рецептов. Kotlin, Jetpack Compose, Material 3, Room. Один модуль `app`, локальная работа без учётной записи.

## Фирменный стиль

В папке [`design/`](design/) — [руководство по стилю](design/BRAND_GUIDE.md), SVG логотипа в трёх композициях, три варианта цвета иконки, монохромный знак, 11 пиктограмм и экспорты 512/192/48 px. Основной вариант — терракотовый дом с сердцем-дымом. Android adaptive icon подключён в ресурсах приложения. `VkusTheme` задаёт светлую и тёмную палитры, типографику Material 3 и базовые размеры; экраны используют эти токены.

## Возможности

- Главная с логотипом, семейными карточками и нижним меню: главная, поиск, добавление блюда, книга, настройки.
- Загрузочный экран с названием «Вкус детства»; системные отступы для строки состояния и навигации Android 15.
- Рецепты: поиск, история, ингредиенты, шаги, редактируемая заметка, несколько фотографий, аудиозаметка.
- Ингредиенты выбираются из локального справочника по 7 разделам; в рецепте количество указывается отдельно. Редкий продукт можно добавить вручную. Ранее сохранённые рецепты остаются читаемыми.
- Люди: фотографии, связь с рецептами, воспоминания.
- Профиль автора: кто ведёт книгу — имя, кем приходится, фото и описание. Рецепт, не подписанный чьим-то именем, выходит от лица автора: в карточке на главной, в списке, на экране рецепта и в главе «Рецепты автора» печатной книги.
- Жизнь рецепта: число приготовлений, семейные версии, три оценки от 1 до 5.
- Подбор по выбранным ингредиентам из собственной коллекции с указанием недостающих продуктов. Список продуктов и свои названия сохраняются на устройстве.
- «Как мы это едим»: самостоятельные семейные фотоистории без обязательной связи с рецептом.
- Подбор рецептов и фотоисторий для PDF-книги с проверкой связи с людьми.
- Настройки с переключением светлой и тёмной темы и полный архив ZIP с импортом и экспортом.

## Сборка

Откройте папку проекта в Android Studio (с JDK 17, Android SDK 35 и Gradle 8.11.1) или запустите `gradle :app:assembleDebug`. Результат: `app/build/outputs/apk/debug/app-debug.apk`. Это временная тестовая сборка; в разных CI-запусках debug-сертификат может меняться. Для сохранения возможности обновления без удаления приложения требуется постоянный закрытый ключ подписи в защищённых секретах CI. Ключ и пароль нельзя добавлять в репозиторий.

На Ubuntu x86_64 сервере с JDK 17, `curl`, `unzip` и доступом к репозиториям Google/Gradle запустите `bash scripts/build-apk-ubuntu.sh`. Скрипт ставит инструменты в домашнюю папку, показывает лицензии Android SDK, скачивает платформу 35 и собирает debug APK. Эмулятор Android для сборки не нужен.

В GitHub `.github/workflows/android-apk.yml` запускается вручную или при push в `main` и отдаёт APK в артефакте `vkus-detstva-debug-apk`. CI проверяет подпись `apksigner`; отдельный workflow устанавливает APK на чистый эмулятор Android 15 и запускает главный экран.

Для установки через USB: `adb install -r app/build/outputs/apk/debug/app-debug.apk`. При неудаче эта команда выдаёт точный код `INSTALL_FAILED_*`, который лучше сообщения файлового менеджера. На телефоне откройте **именно файл `.apk`**, а не ZIP-артефакт GitHub. Разрешите установку неизвестных приложений тому приложению, через которое открываете файл (например, «Файлы» или браузеру). Предупреждение Play Protect для стороннего приложения само по себе не означает повреждённый APK; не отключайте защиту глобально. Если установка блокируется, запишите дословный текст предупреждения и код `adb install`.

**Обновление с предыдущего APK.** Тестовые APK из разных запусков CI могли получить разные сертификаты. Если Android пишет, что пакет конфликтует с установленным приложением: сначала в старом приложении откройте **Настройки → Сохранить полный архив ZIP** и убедитесь, что файл сохранился вне папки приложения. Затем удалите старую версию, установите новую и выберите **Настройки → Восстановить из ZIP**. Удаление без архива уничтожит локальные рецепты и фотографии. Для регулярных обновлений нужен собственный постоянный ключ подписи в защищённых секретах CI.

Готовый файл доступен во вкладке **Actions → Android APK → последний успешный запуск → Artifacts**. Обёртка Gradle (`gradlew`, `gradle-wrapper.jar`, версия 8.11.1) добавлена в репозиторий — локально достаточно `./gradlew :app:assembleDebug` при установленном JDK 17 и переменной `ANDROID_HOME`.

## Данные и ограничения

Архив ZIP содержит редактируемые данные, фотографии, аудио и профиль автора. Храните его отдельно от телефона. Восстановление заменяет текущую коллекцию; перед ним приложение просит подтверждение. Отдельная PDF-книга предназначена для чтения и печати.

## Дорожная карта — что стоит добавить дальше

- Титул и колонтитул книги с именем автора: данные профиля уже есть, осталось вывести на обложку и нижний колонтитул PDF.
- Список покупок: собрать ингредиенты нескольких выбранных рецептов в один список, сгруппированный по разделам каталога.
- Режим «готовим вместе»: пошаговый экран с крупным текстом, таймерами и озвучкой шагов.
- Даты и «в этот день»: напоминания о рецептах, связанных с днями рождения и памятными событиями семьи.
- Отправка рецепта родне: экспорт одной главы или отдельного рецепта архивом или PDF для мессенджеров.
- Резервная копия по расписанию: автоматический ZIP в выбранную пользователем папку.
- Расширенный поиск: уже ищет блюда, людей и продукты — добавить поиск по аудиозаметкам и текстам фотоисторий.
- Печать отдельной главы: выгрузка PDF не всей книги, а выбранного человека или года.
- Общий доступ с контролем: локальная сеть или ссылка на архив для второй семьи без облачного сервера.

Камера открывается через системное действие съёмки, а несколько снимков выбираются через системный Photo Picker. Это убирает постоянное разрешение на доступ ко всей галерее. Видеосъёмка, облако, OCR и внешний каталог TheMealDB в этой версии не реализованы. Для опубликованного приложения TheMealDB требует платный доступ. Покупки через RevenueCat требуют ваших аккаунтов магазинов, продуктов и проверки платёжной географии, поэтому книга пока доступна без оплаты.

## Перед публикацией

APK успешно компилируется в CI, но пока не испытан на физическом Android-устройстве. Проверить импорт/экспорт, права на микрофон, длинные рецепты в PDF, качество фото и поведение после удаления/восстановления. Затем настроить подписанный release, политику конфиденциальности и платежи для конкретных стран.
