# Электронные издания и семейная лента

## Граница текущей версии

Архив и его лента находятся на одном устройстве. «Отправить родне» создаёт отдельный PDF рецепта или подборки одного человека без передачи всей базы. Полный PDF и архив пока доступны по старому сценарию бесплатно. Не включать платную кнопку без работающей проверки покупки и восстановления доступа.

## Контур оплаты для выпуска

1. Бесплатное заполнение архива и просмотр книги внутри приложения.
2. Пользователь выбирает издание и видит итоговую цену из магазина, а не число, встроенное в приложение.
3. Сервер создаёт `editionId`, фиксирует версию состава книги (идентификаторы и хэши содержимого), владельца и тип файла. Покупка относится к этому снимку, а не ко всем будущим редакциям.
4. Только ЮKassa: сервер создаёт платёж с ключом идемпотентности и возвращает приложению `confirmation_url`. Секретный ключ магазина никогда не хранится в APK. После возврата пользователя сервер проверяет статус платежа через API ЮKassa; уведомление `payment.succeeded` также перепроверяется серверным запросом, прежде чем выдавать право на экспорт. Отмены и возвраты отзывают право согласно правилам покупки.
5. После подтверждения клиент сохраняет PDF и может повторно скачать то же издание. Новые редакции оформляются отдельно. Подписка возникает только при наличии реального облачного сервиса.
6. События воронки: `book_preview`, `checkout_started`, `purchase_verified`, `export_completed`. Не передавать рецепты, имена людей или фотографии в аналитику.

Нужны магазин ЮKassa, сервер с секретным ключом, маршрут возврата и HTTPS для уведомлений. Следующая активность — реализация и размещение этого серверного контура. Не хранить право на экспорт только в `SharedPreferences` и не считать возвращение из браузера подтверждением оплаты.

Документация ЮKassa: [быстрый старт](https://yookassa.ru/developers/payment-acceptance/getting-started/quick-start), [процесс платежа](https://yookassa.ru/developers/payment-acceptance/getting-started/payment-process), [входящие уведомления](https://yookassa.ru/developers/using-api/webhooks).

## Общая лента

Сервер хранит семью (`familyId`), участников, рецепты, события с одним или несколькими блюдами и отдельные реакции с уникальным ключом `(familyId, postId, memberId)`. Фото общего стола прикреплены к событию; фото блюда — к рецепту. Вступление по приглашению и отзыв доступа; авторизация для каждого запроса; фото в закрытом хранилище; удаление участника и его данных по запросу. В ленту передаются только выбранные пользователем публикации, а не все поля локального `Person`. При конфликте редактирования нужна явная версия записи. До появления такого сервиса локальная лента не называется синхронизированной.

Физическая печать, типография, доставка и подарочные товары не входят в эту модель.
